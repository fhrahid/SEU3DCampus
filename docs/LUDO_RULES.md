# Ludo rules used by the project

This compact local variant uses one human player against a CPU. Each side has four tokens. A token leaves home only on a six, advances along a 20-space track, and must not move beyond space 20. The player rolls with Space or R, then selects token 1–4. The CPU takes an automatic legal turn. Reaching space 20 with all four tokens wins. N starts a new game.
