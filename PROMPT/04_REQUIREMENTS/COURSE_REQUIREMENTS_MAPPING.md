# Course Requirements → Planned Implementation

| Course Requirement | Planned SEU Implementation |
|---|---|
| Translation | Dedicated transform-demo object controlled by keyboard/mouse |
| Rotation | Transform-demo object + normal scene rotations |
| Scaling | Transform-demo object |
| Complex objects | Staircase, gates, counters, gaming stations, player, Rubik's Cube |
| Continuous rotating object | Delta-time-driven ceiling fan or SEU-appropriate rotating display |
| View outside from scene | Interior glass/window area showing garden/driveway/exterior |
| Two light sources | Exterior sun-like light + interior point/spot light |
| Ambient material | Reusable material presets |
| Diffuse material | Reusable material presets |
| Specular material | Reusable material presets |
| Object coordinate transformation | Model matrix / push-pop transforms |
| Viewing coordinate transformation | Camera / `gluLookAt` or equivalent |
| Textures | Wood furniture, floor tile, wall/concrete/brick, signage/picture |
| Algorithms + CG | Ludo, Rubik's Cube, 2048, Tic-Tac-Toe, Rock Paper Scissors |

## Important

The final program should not merely contain these techniques somewhere in hidden code. Each graded requirement must be easy to demonstrate during the live project presentation.
