# PHASE 15 — Final Packaging + Demo Readiness

## Objective
Prepare the project for submission and live demonstration.

## Deliverables
- clean source code,
- Code::Blocks project/workspace if used,
- build instructions,
- controls document,
- project architecture document,
- reference interpretation document,
- QA report,
- screenshots if convenient,
- no temporary build junk in the submission pack unless required.

Create:
- `FINAL_DEMO_SCRIPT.md`

Demo sequence should include:
1. Start outside.
2. Show SEU exterior.
3. Enter through IN Gate.
4. Walk, run, jump.
5. Cross driveway/garden view.
6. Climb Stair 1.
7. Explore major ground-floor spaces.
8. Show collision.
9. Sit on a chair and stand.
10. Enter gaming room.
11. Demonstrate all five games briefly.
12. Exit back to campus.

## Final Acceptance Gate
A fresh machine with the documented dependencies should be able to compile/run the project, and the demonstrated required features should match the submitted source.


## Mandatory Graphics Demonstration Segment

The final demo script must explicitly show the graded graphics requirements.

Add a short segment that demonstrates:

1. Select the transformation demo object.
2. Translate it.
3. Rotate it.
4. Scale it.
5. Move the camera to prove viewing-coordinate transformation.
6. Show at least two complex objects.
7. Point out the continuously rotating object.
8. Stand inside and show the exterior through a window/glass wall/opening.
9. Show the two-light setup.
10. Show material differences and explain ambient/diffuse/specular behavior briefly.
11. Show textured wood/floor/wall/sign surfaces.
12. Demonstrate that the mini-games use algorithms as well as graphics.

Create `docs/GRAPHICS_REQUIREMENTS.md` mapping every course requirement to:
- implementation file,
- relevant function/class,
- controls,
- scene location,
- how to demonstrate it.
