# PHASE 10 — 2048

## Objective
Implement a complete 2048 mini-game.

## Game Rules
- 4x4 board,
- arrow keys or WASD only while game owns input,
- valid sliding,
- equal-tile merging once per move,
- score,
- spawn new tile after a successful move,
- detect 2048/win state,
- detect no-moves/game-over,
- restart.

## Rendering
Use a simple 2D overlay or 3D board placed in front of the mini-game camera. Readability matters more than fancy effects.

## Important Input Rule
When 2048 is active, movement keys must control the game, not the campus player.

## Acceptance Gate
Run deterministic/manual test cases for merge behavior such as:
- 2,2,2,2 -> 4,4 after a directional move,
- 4,4,8,8 -> 8,16,
- no double-merge of a newly created tile in the same move.
